# Final DevOps File Map

## Terraform

```text
terraform/
├── master.tf
├── terraform.tfvars.example
└── user-data/
    ├── jenkins-bootstrap.sh
    └── sonarqube-bootstrap.sh
```

### `master.tf`
Single combined infrastructure file. It creates networking, IAM, Jenkins, SonarQube, ECR, S3, RDS, Redis and EKS.

## Ansible

```text
ansible/
├── playbook.yml
├── requirements.yml
├── inventory.ini.example
└── README.md
```

`inventory.ini` is generated by Jenkins and is intentionally not committed.

## Helm

```text
helm/kailash-e-store/
├── Chart.yaml
├── values.yaml
└── templates/
    ├── _helpers.tpl
    ├── deployment.yaml
    ├── service.yaml
    └── hpa.yaml
```

## CI/CD

`Jenkinsfile` runs Terraform → Ansible/SSM → Django test → SonarQube → Trivy → Docker → ECR/Docker Hub → Helm/EKS → verification → monitoring.
